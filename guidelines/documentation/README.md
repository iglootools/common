# Documentation Guidelines

How an iglootools project writes and lays out its documentation, its
guidelines included.

| File | Read it when |
|---|---|
| [layout.md](layout.md) | adding, renaming or restructuring `README.md`, `CONTRIBUTING.md`, `AGENTS.md` or anything under `docs/`, including `docs/guidelines.md` and a new area-conventions document |
| [types.md](types.md) | writing a document, or reworking what one says, anywhere in the project; read it with `layout.md` when the document is new or moves |
| [writing-guidelines.md](writing-guidelines.md) | adding or reworking a rule, in the shared guidelines or a project's guidelines files |
| [templates/AGENTS.md.template](templates/AGENTS.md.template) | writing a project's `AGENTS.md` |
| [templates/CONTRIBUTING.md.template](templates/CONTRIBUTING.md.template) | writing a project's `CONTRIBUTING.md` |
| [templates/guidelines.md.template](templates/guidelines.md.template) | writing a project's `docs/guidelines.md` |
