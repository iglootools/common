# Documentation Guidelines

How an iglootools project writes its documentation. Read on demand, like
[project-setup/](../project-setup/): the `guidelines` skill routes to the file a
change reaches.

| File | Read it when |
|---|---|
| [layout.md](layout.md) | adding, renaming or restructuring `README.md`, `CONTRIBUTING.md`, `AGENTS.md` or anything under `docs/` |
| [types.md](types.md) | writing a document, or reworking one: the kinds of document and what makes each good |
| [writing-guidelines.md](writing-guidelines.md) | adding or reworking a rule, in the shared guidelines, or any of a project's guidelines files |
